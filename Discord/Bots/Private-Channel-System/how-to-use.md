# Private VCs 

## Erklär Video:
private-channel.mp4

Hier ist eine kurze Erklärung, wie das dynamische Voice-Channel-System funktioniert:

Ein Nutzer betritt einfach den dafür vorgesehenen Erstellungs-Kanal, welcher in diesem Fall den Namen <span class="sh-glow">"Create it :D"</span> trägt.

Daraufhin spielt der Bot eine kurze Sprachnachricht ab, die den Nutzer bittet einen Moment zu warten, während der Kanal erstellt wird.

Nach einer kurzen Ladezeit generiert der Bot einen eigenen Sprachkanal, der automatisch nach dem Nutzer benannt wird (z. B. <span class="sh-glow">"gamer752's Channel"</span>).

Der Nutzer wird vom System sofort und ohne weiteres Zutun in diesen neuen Kanal verschoben.

Sobald der Nutzer die Verbindung trennt und der Kanal leer ist, wird der temporäre Sprachkanal automatisch wieder gelöscht.
